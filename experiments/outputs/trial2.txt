**Gopher** (pronounced “go-fer”) is an older way to browse and retrieve information over the Internet. It isn’t the Web itself, and it isn’t an early version of HTTP, though it served a similar purpose: helping people find and fetch documents on different servers.

In Gopher, you typically start at a **menu**. Each menu entry names an item and tells the client where to get it—often another menu or a text file, but it can also point to binary files and other kinds of services. When you choose an entry, the client connects to that server and sends a short *selector* identifying the item; the server returns the item and closes the connection. Gopher’s original standard dates to 1993 and uses TCP, conventionally on port 70. <citation src="13"></citation>

HTTP also uses client requests and server responses, but it has a more general message format: requests can specify methods such as `GET` or `POST`, and requests and responses can include headers describing the content and how to handle it. HTTP can carry HTML, images, video, API data, and much more. The **Web** is the larger system built around HTTP, browsers, and formats such as HTML—not just the HTTP protocol alone. <citation src="16,19"></citation>

A useful shorthand is: **Gopher gives you a directory of destinations; HTTP gives the browser a flexible way to request and process resources.** Gopher menus make navigation feel like moving through folders. On the Web, links can be embedded throughout a page, and pages can be styled and made interactive. Gopher can carry more than plain text, but its menus and conventions are much simpler than the Web’s rich page model. <citation src="13,16"></citation>

**Gemini** is a newer, separate protocol that borrows some of Gopher’s minimalist spirit. It was designed much later, beginning in 2019, and aims to offer a text-focused browsing space without the Web’s full complexity. Unlike Gopher, Gemini requires TLS encryption and uses a structured response line with a status code; its typical content format, *Gemtext*, supports simple headings, lists, quotes, and links. <citation src="6"></citation>

So Gemini is best thought of as **Gopher-inspired, not Gopher-compatible**: it keeps the emphasis on lightweight reading, but modernizes the connection and document format. Gopher is organized around menus; Gemini uses linked text documents. Both are alternatives to the full Web, and neither is a mode of HTTP. <citation src="6,21"></citation>
