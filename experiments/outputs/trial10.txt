Gopher (often misspelled “Gophor”) is an early Internet protocol for finding and retrieving documents. Think of it as a **network of menus**: you open a menu, choose an item, and follow its link to another menu or a file. Its menus describe each item with a type, a display name, and the information needed to fetch it—such as a selector, host, and port. <citation src="9"></citation>

**How a Gopher request works:** a client connects to the server—traditionally on TCP port 70—and sends a short selector line. The server replies with a menu, a document, or another resource, then typically closes the connection. A menu entry might point to a submenu, a text file, a search service, or even another server. <citation src="6,9"></citation>

**Compared with the Web and HTTP:** Gopher’s protocol and content model are deliberately spare and menu-oriented. The Web uses HTTP or HTTPS to transfer resources, often HTML pages with links embedded in the text, plus images, stylesheets, scripts, and other files. HTTP also has a richer request-and-response structure; Gopher mostly asks for a selector and returns the selected item. These are tendencies, not hard limits: HTTP can serve plain text, and Gopher can serve binary files. Classic Gopher also does not provide encryption by default. <citation src="6,9,7"></citation>

**Where Gemini fits:** Gemini takes inspiration from Gopher’s simplicity, but it is not just “Gopher with encryption.” A Gemini client sends a full `gemini://` URL and gets a status line followed by content; TLS is built in, and the usual text format, Gemtext, supports headings, lists, quotations, preformatted text, and links. So Gemini keeps a lightweight, reading-focused feel while making links part of the document format and adding a more explicit response protocol. <citation src="11,13,5"></citation>

A rough analogy: **Gopher is like browsing a set of linked directories; the Web is a broad document-and-application platform; Gemini is a smaller, text-focused alternative that borrows the simplicity of Gopher while using its own secure protocol and document format.** <citation src="9,11,5"></citation>
