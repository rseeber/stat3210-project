Gopher is best thought of as a **menu-driven way to browse and fetch files**. A server presents a hierarchy of menus; choosing an item tells the client what to request next. It was designed in 1991, before the Web became dominant, and its basic protocol was documented in RFC 1436. <citation src="5"></citation>

**How a Gopher visit works:** the client connects to the server—usually on TCP port 70—and sends a short selector identifying the requested menu or file, followed by a line ending. A menu contains lines describing items: each has an item type, a display name, and the information needed to reach it. The client turns those entries into a navigable menu. Selecting one sends another request. Gopher can serve more than plain text, but the item type helps the client decide how to handle what comes back. <citation src="5,1"></citation>

**How that differs from the Web and HTTP:** HTTP is the Web’s request-and-response protocol; HTML is one format commonly carried over it. HTTP responses include status and header information, such as the content type. Gopher’s basic protocol is simpler: a client asks for a selector, and the server sends the result without HTTP-style response headers. Its navigation is also more directory-like, while Web pages commonly embed links within documents. <citation src="5,3"></citation>

**Where Gemini fits:** Gemini is a newer, separate protocol whose design was inspired by Gopher. Like Gopher, it aims for lightweight, text-focused browsing. But Gemini adds features Gopher lacks: it requires TLS encryption, uses `gemini://` URLs, returns a status code and metadata, and defines Gemtext—a simple format with explicit link lines and basic text structure. So Gemini is less a direct continuation of Gopher than a modern protocol that shares its minimalist spirit. <citation src="6"></citation>

In short: **Gopher is mostly menus pointing to resources; the Web is a richer hypertext ecosystem built around HTTP; Gemini borrows Gopher’s simplicity while adding encrypted connections and a small native document format.**
