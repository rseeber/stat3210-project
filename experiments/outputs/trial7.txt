Think of **Gopher as a networked directory**, **the Web as a system of linked documents and media**, and **Gemini as a deliberately small, text-focused document network**.

In Gopher, a server usually presents a menu: each entry tells the client what kind of item it is, what label to show, and where to request it (a selector, host, and port). When you choose one, the client sends the selector to the server, which returns a menu or the item’s data. Gopher can serve binary files as well as text, but its characteristic browsing experience is moving through menus and opening files—not following links embedded within richly formatted pages. <citation src="18,16"></citation>

The Web uses HTTP to request resources, but HTTP is only one part of the Web: browsers also interpret formats such as HTML, which can link to other resources and combine text, images, scripts, and styles. HTTP has grown to support many kinds of requests and responses, with headers and extensions for things such as content types, caching, and cookies. Gopher’s core exchange is much simpler: a selector goes in, and the server returns the item, with far less standardized metadata. <citation src="7,8,18"></citation>

**Gemini borrows Gopher’s taste for simplicity, but isn’t just Gopher with a new name.** It uses a document-oriented model with `gemini://` addresses and Gemtext, a minimal format with headings, lists, preformatted text, and links on their own lines. Unlike classic Gopher, Gemini requires TLS; unlike the Web, it intentionally keeps the content format and protocol small. A Gemini request is essentially a URL, and the server responds with a short status line followed by the document or other data. <citation src="11"></citation>

So the relationship is: **Gopher helped inspire Gemini’s minimalist approach; Gemini modernizes that spirit with encrypted connections and a simple linked-document format.** HTTP and the Web offer much more flexibility, while Gopher and Gemini make a narrower, simpler style of browsing possible. <citation src="1,11,18"></citation>
